масс деталей, жёсткость приводов и коробки столкновений остаются приближёнными.
Скорость цели ограничивает команду, а не фактическую скорость сустава.
Отчёт всегда имеет `preview_only=true`, `hardware_validated=false`.

## Открыть редактор

В обычной панели откройте **Гоша → Движения → Motion Studio**. Здесь встроен
полный редактор: исходная модель, шесть ползунков, шкала времени, Live и JSON.
Переключение разделов панели сохраняет черновик; уход из Studio завершает
USB-сессию через STOP. Для Live запустите локальную USB-службу командой ниже.
При первом выборе Live разрешите браузеру доступ `gosha.website` к локальной
сети, затем нажмите **Найти USB**. Это поиск порта; управление не включается.

Отдельный локальный адрес для работы без сервера: **http://127.0.0.1:5176/**.

Из этой папки:

```bash
bash start.sh --background
bash start.sh --status
bash start.sh --stop
```

Первый запуск готовит зависимости и сборку. После подготовки редактор и USB-служба
работают на Python; Node.js нужен для сборки, а интернет для работы не требуется.
Обычный запуск в терминале — `bash start.sh`; остановка — Ctrl+C.
Служба не открывает USB автоматически и не включается при загрузке компьютера.
Перед остановкой сервера нажмите STOP и отключите USB в редакторе.

## Создать движение в 3D

1. Нажмите **Новое движение**, введите название.
2. Выберите конечность щелчком по модели или её названию справа.
3. Настройте угол ползунком или числовым полем. Для числа нажмите Enter или
   перейдите в другое поле. Поза сохраняется на текущей отметке.
4. Выберите следующую отметку на шкале и настройте следующую позу.
   **Записать позу / Обновить позу** сохраняет полный кадр, включая неподвижные суставы.
5. Нажмите **Воспроизвести в 3D**. Модель вращается мышью, колесо меняет масштаб.
6. Нажмите **Сохранить в файл**. JSON можно импортировать обратно.

Названия: **Левая рука, Правая рука, Левая нога, Правая нога, Левая стопа,
Правая стопа**. В виде спереди правая сторона робота находится слева на экране.
Ноль — исходная поза. Подсказка около каждого ползунка объясняет направление:
руки поднимаются и опускаются, ноги поворачиваются вокруг вертикального шарнира,
стопы наклоняются. Эти оси соответствуют исходной сборке `robot.step`.
Файлы и протокол сохраняют прежние координаты; знаки правой руки и левой стопы
преобразуются только при отображении и вводе. Логическому 0° соответствуют
135° правой руки, 45° левой руки и 90° ног и стоп.

## Настроить на роботе в Live

1. Проверьте исходную механическую позу, устойчивую опору и доступность
   выключателя. Для аппаратной пробы действуют условия
   `GOSHA_FIRMWARE/docs/HARDWARE_DEVELOPMENT_POLICY_RU.md`.
2. Выберите **Live → USB → Подключить и управлять**. Проверка возможностей,
   штатная подготовка приводов и открытие сессии выполняются одной кнопкой.
   Подготовка может физически сдвинуть руку в исходную командную позу;
   прежняя цель из редактора автоматически не отправляется.
3. На этом компьютере должен быть один раз настроен ключ Live. Локальная служба
   хранит его вне веб-каталога и не передаёт в браузер. Если ключ не настроен,
   панель предложит указать его в параметрах подключения.
4. Все доступные суставы управляются ползунками справа в одной сессии.
   Доступность и пределы определяет ответ прошивки: прежние версии объявляют
   пять приводов, новые могут объявить шестой — левую руку. Пока прошивка
   не объявила левую руку, она доступна только в 3D. Её рабочий диапазон Live
   ограничен 0…15° относительно нейтрали 45°, скорость — до 5°/с.
5. Дождитесь достижения цели. 3D показывает подтверждённую команду робота;
   команда и цель подписаны отдельно. Нажмите **Записать позу / Обновить позу**,
   чтобы сохранить эту полную позу в кадр движения.
6. Между завершёнными целями можно выбрать следующую отметку шкалы,
   продолжить настройку и записать следующий кадр без повторного открытия сессии.
   Выбор времени сам по себе не двигает робота.
7. **СТОП / Esc** завершают сессию и удерживают текущую позу. STOP не возвращает
   конечности автоматически в ноль. Для возврата сначала задайте 0° ползунком.

Скрытие вкладки, потеря связи и ошибка останавливают управление. Автоматического
возобновления нет. Установленных датчиков угла нет: подтверждение команды
не заменяет наблюдение за реальной конечностью.

## Записать и обновить движение

1. Завершите Live кнопкой **СТОП**, оставьте USB подключённым.
2. Нажмите **Записать в робота**. Для уже записанного проекта кнопка называется
   **Обновить в роботе**. Сохранный ID остаётся прежним.
3. Дождитесь статуса **Установлено**. Studio сверяет CRC и перечитывает каталог.
4. **Проверить в роботе** проверяет пакет программно, без движения приводов.
   **Запустить в роботе** действительно двигает робот; STOP доступен и при
   выполнении пакета, и во время ожидания ответа.
5. Отключите USB и закройте Studio. Включите обычный голосовой режим Гоши,
   чтобы подключить его существующий канал управления к серверу.
   В обычной панели откройте Гошу → **Движения** →
   **Обновить каталог**, выберите название и нажмите **Запустить**. Там же есть
   **Стоп** и **Состояние**. Голос использует тот же каталог `self.motion.*`.

Пакет содержит калибровку и проверяется против возможностей именно подключённого
робота. Углы не обрезаются молча. Слишком быструю последовательность нужно
исправить по времени или амплитуде до записи. Каждый привод проверяется отдельно:
пять прежних приводов могут объявить до 120°/с, левая рука — 5°/с. Старые
прошивки и ранее записанные пакеты сохраняют свои пределы 10°/с или 60°/с.
Ручная скорость при подключении начинается с 5°/с; ползунок скорости показывает
предел выбранного сустава. Ограничение левой руки не замедляет остальные пять.
Темп аппаратного запуска задают времена кадров и ограничения пакета;
настройка ручной скорости его не меняет. Новый пакет содержит пять либо шесть
приводов по объявленным возможностям. Прежние файлы сохраняют координаты и ID,
а обновление существующего движения не создаёт новый ID пакета.

Прошивка хранит **до трёх пользовательских пакетов**, дополнительно к встроенным.
С 3 октября библиотека размещена в отдельном NVS 32 КиБ. Общий объём ограничен:
три пакета максимального размера 12 КиБ туда не помещаются. При нехватке байтов
новая запись отклоняется, действующая версия остаётся доступной.
Обновление существующего ID использует резервный слот; четвёртое новое движение
не вытесняет прежнее. При заполнении памяти появится пояснение. Сначала сохраните
ненужное движение в файл и только затем удалите выбранный пакет. Верхняя кнопка
**Удалить в роботе** удаляет только пакет текущего проекта, а проект остаётся
в Studio. Старые встроенные команды остаются доступными в прежнем темпе.

## Сохранение и восстановление

- Изменения автоматически сохраняются в этом браузере для адреса `127.0.0.1:5176`.
  Для долговременной копии используйте **Сохранить в файл**.
- Импорт сохраняет ID файла. Если проект с таким ID уже существует, редактор
  предлагает обновить его и сохраняет предыдущий черновик в истории.
  Для отдельного нового движения используйте **Копия**.
- **Сохранить версию** добавляет снимок в историю, до 20 на движение.
  После обновления робота предыдущая установленная версия также сохраняется.
- В списке **Восстановить сохранённую версию** есть **Записанная в робота версия**.
  Восстановление сохраняет текущий черновик и меняет проект. Для изменения робота
  затем нажмите **Обновить в роботе**.
- История находится в браузере; обычный JSON содержит движение, а не всю историю.
  Очистка данных сайта или другой браузер требуют импорта сохранённого файла.
- До 100 проектов, 1000 кадров, 120 секунд, 2 МиБ на импортируемый файл.

## Подготовка модели и сборки

Нужны Python 3.10+, NumPy, Node.js 22.12+, npm и браузер с WebGL2.
Исходные STL/STEP и производный GLB остаются в игнорируемом `local_only/`.

```bash
python3 scripts/prepare_model.py \
  --source-dir '<папка Robot с исходными STL>' \
  --output local_only/public/models/gosha.glb
npm ci
npm test
npm run test:bridge
npm run build
```

Сборка требует полной модели; схематичная подмена не используется. В текущей
сборке 589 378 треугольников, 12 деталей, включая кнопку BOOT и выключатель.
Координаты CAD в миллиметрах, Z вверх. `npm run dev` предназначен для разработки;
для обычной работы запускайте `start.sh`.

Протокол — `gosha.motion.live.v1`, профиль — `gosha-preview-v1`.
USB-служба слушает `127.0.0.1:5177`, разрешает только локальный редактор,
панель `https://gosha.website` и USB
`303a:1001`; serial открывается только по явному подключению. Ключи в Git не входят.
