# AGENTS.md

`ops/systemd/` хранит только unit-файлы для серверного контура `GOSHA`.

## Правила

- Не добавляй сюда сервисы, которые мутируют git-репозиторий сами по себе.
- Таймер наблюдателя должен оставаться в режиме только чтения.
- Если меняешь имена сервисов или env-пути, синхронно обновляй `ops/install_server.sh` и `docs/GOSHA_SERVER_DEPLOY_RU.md`.
- Для масштабируемости разносить роли по службам допустимо и желательно: панель, совместимый серверный узел, шлюз ИИ-агентов и наблюдатель не должны сливаться в один неразделимый процесс.

## Язык и формат

- Описывай поведение служб, таймеров и путей русским техническим языком по правилам из `../AGENTS.md`.
- Если упоминаешь состояние службы, пиши понятное русское пояснение рядом с именем службы и её режимом работы.
