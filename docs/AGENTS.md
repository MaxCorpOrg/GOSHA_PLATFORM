# AGENTS.md

Папка `docs/` хранит канонический checkpoint для проекта.

## С чего начинать

- `AGENT_CHECKPOINT_RU.md`
- `PROJECT_STATUS_RU.md`
- нужный runbook по зоне задачи

## Правила

- После значимого изменения проекта обновляй минимум `PROJECT_STATUS_RU.md`.
- Если меняется маршрут входа для следующего агента, обновляй и `AGENT_CHECKPOINT_RU.md`.
- Не используй `docs/` как склад черновиков; фиксируй только то, что реально помогает следующему ходу работ.
