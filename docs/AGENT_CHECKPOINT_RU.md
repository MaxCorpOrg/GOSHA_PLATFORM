# AGENT CHECKPOINT

## Что это за проект

`GOSHA_PLATFORM` — отдельный собственный подготовительный контур для `Гоша`, который больше не должен зависеть от `xiaozhi.me` как от обязательной платформы привязки.

## Как писать новые записи

- Все новые планы, отчёты, объяснения и контрольные точки оформляй русским техническим языком по правилам из `../AGENTS.md`.
- Не используй необъяснённый английский жаргон в обычном тексте.
- Английский оставляй только для команд, путей, имён файлов, веток, коммитов и кода.

## Главные ограничения

- Не трогать `/opt/ai_robot` деструктивно.
- Не публиковать `local_only/`.
- Не возвращать жёсткие зависимости на `xiaozhi.me`.
- Не смешивать `GOSHA_PLATFORM` и `GOSHA_FIRMWARE` в одном рабочем дереве.
- Не тянуть исходники прошивки в `GOSHA_PLATFORM`.

## Ближайший приоритет

- При нормальном канале вернуться к серверу только для отдельной тяжёлой фазы:
  - `cd /opt/gosha_platform/app`
  - `bash ops/install_server.sh --phase backend`
- После подтверждения `backend` перейти в `/home/max/GOSHA_FIRMWARE`:
  - выполнить одноразовый импорт исходной базы `/home/max/MAX_CORP_CORE/AI_ROBOT/xiaozhi-esp32`
  - создать профиль `gosha-otto-v1`
  - окончательно заполнить аппаратный манифест и pin map
  - собрать первый `merged-binary.bin`
