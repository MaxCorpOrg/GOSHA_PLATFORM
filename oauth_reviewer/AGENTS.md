# AGENTS.md

`oauth_reviewer/` — внешний сервис ручной AI-проверки кода для `Pull Request` через `GitHub OAuth`.

## Назначение

- не хранить модельные ключи в secrets репозитория;
- давать вход в сервис через `GitHub OAuth`;
- запускать проверку `Pull Request` вручную из отдельного внешнего backend;
- использовать правила проверки из `AGENTS.md` этого репозитория;
- по возможности опираться на уже авторизованный локальный `Codex CLI`, а не на отдельный HTTP-ключ.

## Правила

- Не логируй `GitHub OAuth` токены, коды авторизации, содержимое cookie-сессий и модельные ключи.
- Ограничивай доступ к проверке через разрешённый список репозиториев.
- Не делай автоматических коммитов, автоматического merge и автоматической отправки изменений в git.
- Если меняется контракт сервиса, синхронно обновляй `docs/GOSHA_OAUTH_REVIEWER_RUNBOOK_RU.md` и контрольные документы проекта.

## Язык и формат

- Описания, сообщения об ошибках и review-подсказки пиши нормальным русским техническим языком.
- Не используй русско-английский суржик в обычном тексте.
- Если термин технический важен, пиши его по-русски или сразу поясняй смысл по-русски.
- Для типовых слов используй такие формы:
  - `verified online` — подтверждённо в сети
  - `detect` — обнаружение
  - `handshake` — проверочный обмен запрос-ответ
  - `scope` — область изменений
  - `branch` — ветка
  - `commit` — коммит
  - `push` — отправка изменений
  - `pull` — получение изменений
- Английский оставляй только в коде, API-путях, HTTP-заголовках, именах переменных и env-переменных.
