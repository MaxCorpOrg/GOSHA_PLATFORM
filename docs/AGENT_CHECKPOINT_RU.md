# AGENT CHECKPOINT

## Что это за проект

`GOSHA_PLATFORM` — отдельная масштабируемая платформа `Гоша` для роботов, панели оператора и совместимого голосового серверного узла.

## Как писать новые записи

- Пиши отчёты, планы и контрольные точки русским техническим языком по правилам из `../AGENTS.md`.
- Не используй необъяснённый англо-русский суржик в обычном тексте.

## Текущая рабочая точка

- Ветка:
  - `agent/bootstrap-gosha`
- Актуальный верхний коммит смотри через:
  - `git -C /home/max/GOSHA_PLATFORM log --oneline -1`
- На сервере рабочая копия `/opt/gosha_platform/app` выровнена с этой веткой.

## Главный незакрытый блокер

- Базовый живой голос уже работает.
- Текущий технический хвост теперь не в связности, а в качестве и устойчивости:
  - нужно проверить серию повторных пробуждений
  - нужно проверить серию повторных русских запросов
  - нужно оценить влияние несовпадения частоты:
    - сервер `16000`
    - устройство `24000`
- Для мобильного контура ближайший незакрытый шаг теперь пользовательский:
  - робот может подключиться через приложение
  - но локальный портал `192.168.4.1` в одном из прогонов давал пустую страницу
  - значит мобильный сценарий надо дополировать отдельно

## Ближайший приоритет

1. На устройстве `gosha-main` прогнать несколько подряд живых голосовых циклов.
2. Проверить качество звука и решить вопрос частоты `16000 -> 24000`.
3. Если потребуется смена ключа или профиля поставщика, перезапустить лёгкий контур:
   - `bash /opt/gosha_platform/app/ops/install_server.sh --phase panel`
4. Проверить:
   - `POST /api/internal/openai/v1/chat/completions`
   - что `gosha-main` устойчиво отвечает голосом
   - что в панели нет критичной ошибки по поставщику ИИ
5. Проверить новый мобильный контур:
   - подтверждённые шаги:
     - установка `GOSHA_MOBILE`
     - ввод кода подключения
     - поиск `GOSHA-*`
     - итоговое подключение робота к домашнему `Wi‑Fi`
   - незакрытые шаги:
     - живой радиотест переходного `Xiaozhi-*`
     - устойчивое рабочее открытие `192.168.4.1`
     - переход в главное меню после настройки робота без лишних перезапусков
6. Потом переходить к второй очереди:
   - применение экранных профилей
   - применение пробуждения
   - рабочая база знаний
