## Причина

Голосовая служба завершалась ещё до открытия порта. Журнал содержит
`MotionControlServer.__aenter__` → `mkdir('/run/gosha')` →
`OSError: [Errno 30] Read-only file system`. На 12:32:08 МСК — 41
автоматический перезапуск и отказ соединения с портом голоса; панель
продолжала отвечать HTTP 200. Свободны около 123 ГБ диска и 9,4 ГиБ памяти.

Установленный маршрутизатор дополнен локальным каналом панели движений
`gosha_motion_control.py`; он создаёт `/run/gosha/motion-panel.sock`.
В службе сохранялась защита `ProtectSystem=strict`, а запись разрешалась
только в каталоге данных приложения. Управляемый службой каталог `/run/gosha`
не был объявлен. Изменения семейного ускорения сохранены; точные хэши
действующих файлов записаны в закрытой контрольной точке.

## Исправление и проверка

На сервер добавлен `gosha-voice-router.service.d/30-motion-runtime.conf`:

```ini
[Service]
RuntimeDirectory=gosha
RuntimeDirectoryMode=0700
ReadWritePaths=/run/gosha
```

Каталог создаёт менеджер служб до запуска процесса. Это соответствует
[описанию RuntimeDirectory в systemd.exec](https://github.com/systemd/systemd/blob/main/man/systemd.exec.xml).
Прежний доступ к данным приложения и `ProtectSystem=strict` сохранены.
Шаблоны `ops/systemd/gosha-voice-router.service` в семейной ветке и
рабочей копии панели движений получают те же настройки при новой установке.
Изменения рабочей копии панели движений остаются отдельно, без общего коммита
с её незавершённой разработкой.

Перед установкой: проверка кандидата `systemd-analyze verify` PASS;
отдельная временная служба с настоящей защитой воспроизвела Errno 30.
С исправленными настройками настоящий `MotionControlServer` создал
сокет, обработал некорректный локальный запрос без обращения к устройствам,
закрыл сокет и удалил его. Каталог 0700, сокет 0600, PASS. Команд роботу нет.

Перед заменой сохранены настройки службы; голосовых соединений не было.
Перезапущена только голосовая служба. В 12:38:20 МСК — active/running,
HTTP 200, NRestarts=0. Независимая проверка 12:41:31 МСК: голос и панель
HTTP 200, NRestarts=0, хэши приложения и новой настройки совпадают,
локальный сокет существует. В журнале принято подключение робота
12:39:21 МСК; на момент проверки голосовое соединение остаётся открытым.
