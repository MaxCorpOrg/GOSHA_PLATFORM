## Где остановились

- Проект находится на этапе интеграционной стабилизации перед выпускной приёмкой.
- Android на `TECNO LI9` прошёл полный цикл `MENU -> GOSHA-A-* -> портал -> done.html -> домашний Wi-Fi -> MENU` без отката назад.
- Установленный APK совпал с артефактом сборки, SHA-256 `d353aafb47491f443c8290f999b6827ef1044077cbb189623fec872655e60ec7`.
- Робот после возврата найден по `192.168.1.159`; панель получила `mobile_presence = home_wifi_local` и `local_host`.
- На `TECNO/Transsion` фон стабилен дольше трёх минут только после выбора `BatteryLab -> Нет ограничений`.
- Две последовательные голосовые Wi-Fi-подсказки прозвучали нормально, но чистой диагностики нет: UART заполнен `WSControl`, а `wifi_prompt_diag` отсутствует.
- Общий ограничитель громкости `30` отвергнут как слишком тихий.
- Главный P0:
  - устранить или жёстко ограничить Android `WSControl`-шторм;
  - прошить текущий head прошивки;
  - доказать активный OTA-раздел двумя источниками;
  - получить чистые `wifi_prompt_diag` без Android-нагрузки.
- Продуктовый код платформы пока менять не требуется. Её обязанность — честно показывать свежесть `mobile_presence` после TTL 180 секунд.
