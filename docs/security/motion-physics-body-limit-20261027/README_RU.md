## Что исправляет патч

Раньше `POST /api/physics/jobs` ограничивал 2 МиБ только по `Content-Length` — размеру, заранее объявленному клиентом. При `Transfer-Encoding: chunked`, то есть порционной передаче без заранее объявленной длины, проверка пропускалась.

Патч добавляет потоковое чтение фактических байтов тела до разбора JSON:
- предварительное отклонение объявленного превышения сохранено;
- накопление тела ограничено 2 097 152 байтами;
- функция явно читает максимум 2 097 153 байта для определения превышения, затем возвращает HTTP 413;
- размер проверяется в байтах, не символах; корректные тела ровно на границе принимаются;
- JSON-разбор, проверка модели и запуск работы при превышении не выполняются;
- проверки источника запроса, типа данных, готовности среды и жизненный цикл работ сохранены;
- общий предел 16 МиБ для экспорта больших отчётов не снижен и не снят.

Предел явного чтения функции **не равен пределу всей памяти** сетевых буферов, распаковщика или сервера при множестве запросов. Нагрузочная устойчивость и лимит памяти этим не доказаны.

Патч меняет только `platform/motion_studio/bridge/physics_server.py` и добавляет `platform/motion_studio/tests/test_physics_body_limit.py`. Код USB, прошивки, разговора, телефона, служб Гоши и сам физический движок не меняются.
