## Что уже можно попробовать

`bin/try_jev.py` отправляет завершённую текстовую реплику настоящему JEV,
проверяет ответ и вызывает неизменённый `DeviceTools` из рабочего голосового
кода. На другом конце MCP находится имитатор. Программа не содержит USB,
адреса робота или подключения к рабочим службам. Дополнительных библиотек нет.

Поддержаны взмах правой рукой, шаги вперёд/назад, батарея, состояние и остановка.
Составные команды, точное количество шагов, недоступная рука и неизвестные
действия требуют уточнения. Контекст предыдущей реплики пока не используется.
Остальные встроенные движения не удалены: они просто не включены в эту пробу.

Из корня этой рабочей копии:

```bash
python3 bin/try_jev.py --key-file /путь/к/закрытому/ключу --text 'Гоша, помаши рукой'
python3 bin/try_jev.py --key-file /путь/к/закрытому/ключу --output local_only/jev-trial/results.json
python3 -B platform/test_gosha_jev_trial.py
```

Вместо файла можно задать `TYPESAFE_API_KEY`. Сам ключ в аргументы не передавать.
Вывод содержит выбранную категорию, вероятность, время запроса, отправленный
MCP и результат имитатора. Без `--text` запускаются 20 фиксированных примеров.
Порог вероятности 0,90 экспериментальный; это не оценка точности модели.

Результат сохранён локально: `local_only/jev-trial-20260923/results.json`.
Это первая авторская выборка, без настройки по полученным ответам, не
оценка производственной точности. Время старой разговорной модели, распознавание,

Голосовая служба не импортирует эксперимент. Остановка в текстовой пробе
также выбирается JEV; независимая остановка нужна перед подключением робота.
Синхронный HTTP-клиент предназначен только для отдельной последовательной пробы.

## Дальнейшие действия — коротко

1. Проверить свои фразы этим же запуском и сравнить ответы/время.
2. Подключить диспетчер в отдельном голосовом экземпляре. Сначала проверить
   границу законченной реплики и исключить второй вызов от прежней модели.
3. Попробовать на Гоше и сравнить с обычным режимом.
4. Если результат устраивает — слить изменение в актуальную рабочую ветку
   и выпустить. Если нет — оставить эксперимент и продолжить прежнюю версию.

Рабочая версия уже сохранена в исходной ветке. Пока эксперимент локален,
отказ от него означает просто перестать запускать `try_jev.py`.
