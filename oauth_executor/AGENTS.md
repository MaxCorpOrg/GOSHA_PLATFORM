# AGENTS.md

`oauth_executor/` — локальный исполнительный агент `Codex`, который читает замечания по `Pull Request`, вносит правки в отдельной рабочей копии, коммитит и отправляет изменения в ветку.

## Назначение

- запускать отдельный исполнительный контур локально на этой машине;
- не править основной рабочий каталог напрямую;
- работать через отдельную рабочую копию `git worktree`;
- использовать локальный `codex exec` как исполнительный агент;
- поддерживать ручной запуск через `GitHub OAuth` и автоматический запуск по webhook.

## Правила

- Не логируй `GitHub OAuth` токены, сервисные `GitHub` токены, `OpenAI` ключи, cookie-сессии и приватные URL с токенами.
- Не отправляй изменения прямо в защищённую базовую ветку; работай только с head-веткой конкретного `Pull Request`.
- Не делай автоматический merge.
- Все рабочие копии сервиса держи вне основного git-состояния, под `local_only/`.
- Если меняется контракт сервиса или его автоматический цикл, синхронно обновляй:
  - `docs/GOSHA_OAUTH_EXECUTOR_RUNBOOK_RU.md`
  - `docs/CODEX_PR_FLOW_RU.md`
  - контрольные документы проекта

## Язык и формат

- Пояснения по исполнителю, автоматическим правкам и ошибкам пиши нормальным русским техническим языком.
- Не используй русско-английский суржик в обычном тексте.
- Если термин технический важен, пиши его по-русски или сразу поясняй смысл по-русски.
- Для типовых слов используй такие формы:
  - `verified online` — подтверждённо в сети
  - `detect` — обнаружение
  - `handshake` — проверочный обмен запрос-ответ
  - `scope` — область изменений
  - `branch` — ветка
  - `commit` — коммит
  - `push` — отправка изменений
  - `pull` — получение изменений
- Английский оставляй только для команд, путей, имён файлов, переменных, веток, коммитов и кода.
