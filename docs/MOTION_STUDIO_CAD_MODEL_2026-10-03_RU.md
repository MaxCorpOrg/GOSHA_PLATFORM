## Оси и стороны

CAD использует миллиметры: Z вверх, лицевая сторона направлена к −Y,
левая сторона самого робота — +X. В виде спереди правая сторона робота
находится слева на экране. Имена суставов прошивки сохранены; координатный
суффикс ID не используется для определения стороны детали в CAD.

| Конечность | ID команды | Деталь CAD | Центр вращения, мм | Ось |
|---|---|---|---|---|
| Левая рука | `arm_negative_x` | `arm_positive_x`, `hand_positive_x` | `[50, 0, -7]` | Y |
| Правая рука | `arm_positive_x` | `arm_negative_x`, `hand_negative_x` | `[-50, 0, -7]` | Y |
| Левая нога | `leg_negative_x` | `leg_positive_x` | `[25.5, 0, -40]` | Z |
| Правая нога | `leg_positive_x` | `leg_negative_x` | `[-25.5, 0, -40]` | Z |
| Левая стопа | `foot_negative_x` | `foot_positive_x` | `[25.5, 0, -71.5]` | Y |
| Правая стопа | `foot_positive_x` | `foot_negative_x` | `[-25.5, 0, -71.5]` | Y |

Основание измерений — цилиндрические посадочные поверхности STEP:
плечи корпуса `#53771`, `#53812`, `#55192`, бедренные отверстия `#49859`,
`#50667`, оси стоп `#24100`, `#26430`, `#27073`, `#29420`.
Для вертикальной оси бедра точка по Z может быть выбрана в любом месте
той же осевой линии; в редакторе выбрана граница корпуса и ноги −40 мм.
Трансформации сборочных экземпляров STEP единичные. SHA-256 STEP:
`ef3e561340f95ba7afd3c746786c2d3390894dbf5306c6283be476abbb21e458`.

Прежняя схематичная модель использовала X для ног и стоп и другие
приблизительные центры. По реальной конструкции нога поворачивается
вокруг вертикали, а стопа наклоняется. Подсказки теперь описывают
соответствующий сустав: подъём руки, поворот ноги, наклон стопы.
Знак преобразования 3D, преобразование ползунка правой руки, сериализация
поз и аппаратные команды сохраняют прежнее соглашение. Проверка CAD
не заменяет наблюдение за направлением реального привода.

## Загрузка и запуск

`prepare_model.py` включает кнопку и выключатель, если они присутствуют;
прежние наборы из шести обязательных STL поддерживаются. Дополнительные
детали неподвижны. Неизвестные, повторяющиеся или трансформированные
детали по-прежнему отклоняются до изменения сцены.

`start.sh` требует готовый GLB. Автоматическая подмена сборки квадратиками
убрана; ошибка загрузки показывается в панели. Камера рассчитывает
начальный масштаб по габаритам сборки. Заголовок переносится на несколько
строк в узком окне; блок параметров расположен после ползунков.

Редактор запущен локально на `http://127.0.0.1:5176/` через
`gosha-motion-studio.service` из указанной рабочей папки. USB-соединение
с роботом не открывалось; проверка выполнялась в 3D.
