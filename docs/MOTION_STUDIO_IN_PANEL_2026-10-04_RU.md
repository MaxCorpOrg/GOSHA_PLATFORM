Это сборка из рабочей папки

Редактор загружается с HTTPS панели по защищённому маршруту
`/api/operator/motion-studio/`. Сервер выдаёт только HTML, собранные JS/CSS
и `models/gosha.glb`; исходники, ключи и рабочие файлы недоступны.

Выгрузка JSON проходит через отдельный защищённый маршрут и обычную загрузку
файла браузером. На сервере движение не сохраняется при такой выгрузке.

## Работа в панели

- Обновления телеметрии сохраняют встроенный редактор и черновик.
- Переход в другой раздел оставляет черновик; активный USB завершается через
  существующий STOP с ожиданием подтверждения. Автоматического ARM нет.
- При подключённом Studio обычная кнопка запуска движения заблокирована.
  Обычная кнопка «Стоп» запрашивает завершение сеанса в Studio.
- Обмен между панелью и редактором содержит только состояние связи и запрос
  завершения; источник сообщения и отправитель проверяются. Ключи, углы и
  пакеты остаются внутри редактора и прежнего протокола робота.
- При ширине панели 800–950 px модель и ползунки стоят рядом. Библиотека и
  инспектор прокручиваются отдельно, кнопки копии/удаления доступны.
- Числа и название движения фиксируются по Enter или выходу из поля;
  прежние ограничения Live и проверка углов сохранены.

Для USB локальная служба на `127.0.0.1:5177` дополнительно разрешает ровно
`https://gosha.website`. Доступ к другим сайтам не добавлен. Для первого
поиска браузер может запросить разрешение доступа к локальной сети:
разрешить его и нажать «Найти USB». Поиск перечисляет только `303a:1001` и
не открывает serial. Контроль единственного владельца USB прежний.
Сведения о разрешении: [документация Chrome](https://developer.chrome.com/blog/local-network-access).

Библиотека браузера привязана к адресу сайта: локальные проекты на 5176
не переносятся в HTTPS автоматически. «Малое приветствие» владельца
импортировано из его JSON с сохранением ID и кадров. История локального
адреса и отметки прежних установок не объявлены перенесёнными.
