# GPT-Live: переход на GPT-5.6 Luna — 14 сентября 2026

По прямому выбору владельца рабочий профиль Гоши переключён с GPT-5.5
(`medium`) на **gpt-5.6-luna**, `reasoning.effort=low`. Установка серверных
файлов и профиля завершена 08:47:57 UTC. GPT-Live-1, Meridian, одновременный
приём микрофона и звука, а также доступные функции робота сохранены.
Прошивка в этом переключении не записывалась; проверочные движения роботу
не отправлялись.

## Выбор модели и панель

`session_config` разрешает GPT-5.5 и точный API ID `gpt-5.6-luna`. Явный
`assistant.model_override` имеет приоритет над моделью поставщика.
В API настроек `voice_runtime.reasoning_model` и карточке робота теперь
показывается фактически выбранная модель. Поля и маршруты API не изменены.
Инструкции делегации используют выбранную модель, контракт инструментов
и `parallel_tool_calls:false` сохранены.

Изменён только активный профиль ассистента Гоши: модель, глубина рассуждений,
подпись и время обновления. Поставщик с GPT-5.5, другие ассистенты, привязки
и файлы окружения сохранены с проверкой контрольных сумм. Ключ повторно не
выпускался. Существующие профили GPT-5.5 и цепочка ASR → модель → TTS работают
по-прежнему.

## Проверки

13 этапов `bash bin/ci_validate.sh` PASS, включая 28 голосовых тестов,
20 тестов инструментов, 3 проверки эха и 9 проверок прежнего модуля движений.
Проверены Python AST, синтаксис JavaScript фактического серверного HTML и
`git diff --check`.

Через настоящий API с ключом владельца GPT-Live принял Luna; вычисление
17 × 23 дало 391, получен слышимый PCM с выбранным Meridian, сессия корректно
закрылась. Пять запросов на имитаторе инструментов прошли:

- вперёд: чтение каталога и точный `builtin/walk_forward`;
- назад: чтение каталога и точный `builtin/walk_backward`;
- немедленная остановка: `robot_stop_motion` без нового запуска;
- «Не двигайся, просто скажи…»: никаких вызовов движения;
- заряд: `robot_battery`, итог использовал полученные 42, а не догадку.

`ops/probe_live_commands.py` использует имитатор без транспорта к роботу.
Продолжение функций отслеживается по `response.output_item.done` и
`response.completed`: массив output в последнем событии Live может быть
пустым, поэтому его нельзя использовать как признак отсутствия вызова.
Это короткая проверка миграции, не измерение качества всех разговоров.
После предложенных проверок заряда, взмаха и перебивания владелец сообщил:
«Всё нормально, всё работает». Затем сообщил о таймере отключения;
исправление описано в GOSHA_LIVE_NO_AUTOCLOSE_RU.md.

## Установка и откат

Перед записью сверены SHA-256 действующих файлов и кандидатов, сохранены
исходные файлы и JSON профиля. Установлены `gosha_live_protocol.py`,
`gosha_assistant_store.py` и точечная правка `panel_index.html`. Серверный HTML
отличался от ветки; его посторонние изменения сохранены, поэтому SHA HTML
не совпадает с полным файлом из git. Python-файлы совпадают с веткой.
Перезапущены только `gosha-voice-router.service` и `gosha-panel.service`;
вторая служба перечитывает Python-код настроек. Тяжёлый backend не перезапускался.
После установки проверены суммы файлов и эффективная модель. Голосовой
health основного сервера и промежуточного узла: HTTP 200, ok=true; API панели
доступен. Прежние файлы и профиль находятся в закрытой резервной копии.
Для возврата модели достаточно выбрать `gpt-5.5` и прежний `medium` в
профиле ассистента; это применяется со следующего голосового соединения.
Секреты, идентификаторы роботов и реальные адреса в git не записаны.

Закрытые результаты: AI_ROBOTS/local_only/luna-switch-20260914/
(`predeploy-output.jsonl`, `deployment-result.json`, `external-health.json`,
`ci.log`); серверная копия дополнительно содержит backup/manifest.json и
результат чтения модели через API панели.

## Стоимость

По [документации Luna](https://developers.openai.com/api/docs/models/gpt-5.6-luna)
вход стоит $0.20, кэшированный вход $0.02, выход $1.20 за миллион токенов.
Для [GPT-5.5](https://developers.openai.com/api/docs/models/gpt-5.5) —
$5.00/$0.50/$30.00 соответственно: цена одинакового количества токенов
мышления ниже в 25 раз. Это не сокращение числа токенов и не уменьшение
полного голосового счёта в 25 раз: GPT-Live оплачивается отдельно.
[Руководство делегации Live](https://developers.openai.com/api/docs/guides/live-delegation)
предлагает Luna для задач с ограничением стоимости и подтверждает
независимый выбор голосовой модели и модели мышления.
